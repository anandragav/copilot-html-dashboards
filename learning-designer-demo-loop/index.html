Learning Designer

A request is filled in a structured document form and saved as a Learning Request Brief. One click on Create Learning Dashboard asks Copilot in SharePoint to run the learning-designer site skill, and a self-contained, interactive HTML learning dashboard lands in the library. Drawn live in HTML, not recorded: drag the clock or pick a step.

Prototype. Built with Meng To's open-source HTML Demo skill (MIT).
